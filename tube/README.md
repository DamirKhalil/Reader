# Чернила

Видеотека о писателях и писательстве: интервью, мастер-классы, разборы.

- `index.html` — сам сайт (поиск, фильтры по формату и языку, страницы авторов, курсы-плейлисты, «Отложенное», форма добавления).
- `catalog.js` — каталог. Новое видео = одна строка в `VIDEOS`, новый курс = строка в `COURSES`.

Запуск локально (плееру YouTube нужен адрес http, с `file://` он может не играть):

    cd tube && python3 -m http.server 8000

Затем откройте http://localhost:8000. Для публикации подойдёт GitHub Pages.
